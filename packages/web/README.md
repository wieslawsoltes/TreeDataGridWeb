# @treedatagrid/web · 0.1.0

JavaScript TreeDataGrid native browser custom element.

See the full source archive README and docs for integration, parity boundaries and validation. TypeScript declarations are provided in `index.d.ts`.

Import `index.js` to register `<tree-data-grid>`, then assign `element.Model` to a Core source. The web package requires the companion `@treedatagrid/core` package at the same scoped sibling location. It requires a browser DOM.

A substantial working port, not certified exhaustive Avalonia/.NET API parity. MIT; upstream notice retained in LICENSE.
