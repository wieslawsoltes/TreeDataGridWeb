# TreeDataGridWeb 0.1.0

First public npm release: `@wieslawsoltes/treedatagridweb`.

- Ships the existing DOM-independent Core models and native `<tree-data-grid>` control together, preserving shared constructor identity and relative source imports.
- Exposes typed root/Core/web entry points, the embedded component CSS as an optional asset, and global/standalone browser distributions.
- Adds verified release publication with immutable GitHub assets, checksums, npm provenance, installed consumers, public registry verification and anonymous package installation.
- Retains the existing showcase and its Pages deployment, adds installed-browser tests, and verifies Node 22 and Node 24 consumers.

The existing documented Avalonia/.NET API adaptations and feature boundaries remain applicable; this packaging release does not claim additional upstream feature parity.
